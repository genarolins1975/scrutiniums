# Registros de execução

Saídas dos comandos indicados no relatório, com códigos de cor e finais de linha de progresso normalizados para leitura no repositório. Resultados, falhas, avisos e contagens foram preservados. O timeout intermediário não representa a repetição final aprovada. Os nomes identificam o commit correspondente; o ajuste final após a suíte completa foi restrito ao acabamento de MeusRecortes e revalidado por verificação rápida, build e navegador.
